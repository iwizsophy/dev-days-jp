# 🎮 Mona Mayhem — GitHub Copilot ワークショップ

> **所要時間：** 約1時間<br>
> **難易度：** 中級<br>
> **技術構成：** Astro / Node.js / TypeScript

GitHub のコントリビューションを比較するレトロなアーケード風アプリ **Mona Mayhem** を作りながら、GitHub Copilot のさまざまな開発手順を学びます。**VS Code と GitHub Copilot CLI の2つのトラック**から選べます。

## 🎯 トラックを選ぶ

- **VS Code：** エディター内で Chat、Plan Mode、Agent Mode、バックグラウンドエージェント、組み込みのレビューを体験します。
- **CLI：** ターミナル内で `copilot`、`@file` によるコンテキスト指定、`/plan`、自律的な編集、`/fleet`、`/delegate`、`/review` を体験します。

好みの開発環境に合わせて選んでください。この日本語版では各章に両方の手順を載せています。自分のトラックの節だけを実行し、共通の節へ進みます。

## 📋 開始前のチェック

- [ ] 自分のアカウントで GitHub Copilot が有効になっている
- [ ] Node.js がインストールされている
- [ ] Git がインストールされ、設定済みである
- [ ] ブラウザーとターミナルを使える

### VS Code の場合

- [ ] VS Code **v1.107以上**で、適用待ちの更新がない
- [ ] **GitHub Copilot** 拡張機能にサインインしている
- [ ] Chat パネルを開き、Agent を使える

### CLI の場合

- [ ] GitHub Copilot CLI を導入し、`copilot` コマンドを実行できる
- [ ] `/login` で認証済みである
- [ ] `/help`、`/plan`、`/review` などのスラッシュコマンドを使える

> **ヒント：** VS Code ですぐに始めたい場合は、設定済みの DevContainer を利用できます。

## 🧠 学ぶこと

| 番号 | スキル | 内容 |
| --- | --- | --- |
| 1 | コンテキストの設計 | 指示、参照ファイル、明確な制約でコードベースを Copilot に伝える |
| 2 | 計画から始める | 実装前にアーキテクチャを考える |
| 3 | エージェントによる実装 | 自分で監督しながら、複数手順のコーディングを任せる |
| 4 | デザインの反復 | 見た目を変更し、操作の細部を調整する |
| 5 | 並列作業 | エージェント、セッション、委任タスクに作業を分ける |

### VS Code で重点的に使う機能

- **Chat と Ask モード：** コードの探索
- **Plan Mode：** アーキテクチャとデザインの計画
- **Agent Mode：** 複数ファイルの実装
- **バックグラウンド／クラウドエージェント：** 並列での仕上げ

### CLI で重点的に使う機能

- `copilot` による**対話セッション**
- `/plan` と Shift+Tab による**計画**
- 許可の確認と `/diff` を伴う**自律的な編集**
- `/fleet`、`/delegate`、`/review` による**並列処理と品質確認**

## 💡 進め方のヒント

1. **ブラウザーを開いておく：** 編集による変化をすぐ確認します。
2. **こまめに commit する：** 動作する状態を保存します。
3. **実装前に計画を磨く：** 計画を具体化するほど、結果を評価しやすくなります。
4. **変更をレビューする：** 差分表示や CLI のレビューを使い、内容を確認して採用します。
5. VS Code では、意図から外れたときにチャットの checkpoint や Undo を使えます。CLI では `/session`、`/context`、`/share file` で作業状況を確認・保存できます。
