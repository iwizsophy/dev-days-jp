# 🎉 発展課題

GitHub の対戦アプリが完成しました。ここからは自由課題に挑戦します。VS Code では **Agent Mode**、CLI では `@file`、`/plan`、通常モード、`/review` を組み合わせてください。

## 🏆 課題1：勝者バナー

両方のグラフを読み込んだ後、合計を比較して勝者を表示します。

**作るもの：**

- 2人のコントリビューション合計を比較する。
- 差があれば **「🏆 {username} WINS! 🏆」** を華やかに表示する。
- 同点なら **「🤝 IT'S A TIE! 🤝」** を表示する。
- アニメーションや紙吹雪で演出する。

**プロンプト例：**

```text
両方のコントリビューションデータを読み込んだら、合計を比較して勝者バナーを表示してください。
多いユーザーには「🏆 {username} WINS! 🏆」、同点なら「🤝 IT'S A TIE! 🤝」を表示し、CSS アニメーションで華やかにしてください。
```

## 🏆 課題2：連続日数カウンター

各ユーザーが連続してコントリビューションした最長日数を求めます。

**作るもの：**

- データを日ごとに調べる。
- 1件以上のコントリビューションが続いた最長の日数を求める。
- 各ユーザーの連続日数を目立つように表示する。
- 連続日数が長いユーザーを強調する。

**プロンプト例：**

```text
各ユーザーのデータを分析して、コントリビューションが途切れず続いた最長日数を求める機能を追加してください。
各グラフの下に「🔥 Longest Streak: X days」と表示してください。
```

## 🏆 課題3：対戦履歴

結果を保存し、過去の対戦を見られるようにします。

**作るもの：**

- ユーザー名、合計、勝者、日時を `localStorage` に保存する。
- 対戦領域の下に **Recent Battles** を追加する。
- 直近5～10件を表示する。
- **Clear History** ボタンを付ける。

**プロンプト例：**

```text
比較が終わるたびに対戦結果を localStorage に保存してください。
「Recent Battles」に直近10件のユーザー名、コントリビューション合計、勝者、対戦日時を表示し、「Clear History」ボタンを付けてください。
```

## 🏆 課題4：効果音

外部音声ファイルを使わず、Web Audio API でレトロな効果音を作ります。

**作るもの：**

- Battle! を押したときの**コイン投入音**
- 結果を取得できたときの**パワーアップ音**
- ユーザー不在や API 障害時の**爆発音**
- ミュートの切り替えボタン

**プロンプト例：**

```text
音声ファイルを使わず、Web Audio API でレトロアーケード風の効果音を追加してください。
対戦開始にコイン投入音、結果取得にパワーアップ音、エラー時に爆発音を鳴らしてください。
oscillator と gain node で生成し、ミュート切り替えを付けてください。
```

## 🏆 課題5：対戦開始アニメーション

結果の前にカウントダウンを表示します。

**作るもの：**

- Battle! を押すと全画面オーバーレイを表示する。
- **3… → 2… → 1… → ⚡ FIGHT! ⚡** をアニメーションで表示する。
- その後、グラフを印象的な演出で表示する。
- CSS アニメーションまたは JavaScript で時間を制御する。

**プロンプト例：**

```text
Battle! を押したときに対戦開始アニメーションを追加してください。
オーバーレイに「3...」「2...」「1...」「⚡ FIGHT! ⚡」を約1秒ずつ表示し、その後に結果をスライドインさせてください。
```

## 🏆 課題6：グラフの凡例

コントリビューショングラフに合う色の凡例を追加します。

**作るもの：**

- 活動量の段階を示す横並びの凡例
- **Less** から **More** のラベル
- GitHub のコントリビューション API のレスポンスに含まれる実際の配色
- グラフの近くへの配置

**プロンプト例：**

```text
グラフの下に、API の配色を使った凡例を追加してください。
「Less」の最も薄い色から「More」の最も濃い色まで、色付きの四角形を横に並べ、レスポンスの実際の活動量の色に合わせてください。
```

## 🏆 課題7：結果の共有

1回のクリックで対戦結果をコピーできるようにします。

**作るもの：**

- 対戦後に表示する **📋 Share Results** ボタン
- 整形した要約のクリップボードへのコピー
- ユーザー名、合計、勝者を含む内容
- 短時間表示する **Copied!** メッセージ

**プロンプト例：**

```text
整形した対戦の要約をクリップボードにコピーする「📋 Share Results」ボタンを追加してください。
両方のユーザー名、コントリビューション合計、勝者を含めてください。
Clipboard API を使い、「Copied to clipboard!」という確認を短時間表示してください。
```

## 💻 CLI の追加練習

- `copilot -p "現在の git diff に対する Conventional Commits 形式のメッセージを提案してください。ファイルの変更や commit はしないでください"` で、Git に貼り付けるメッセージだけを生成します。
- `/share file` でセッションを Markdown に保存します。
- `/session` と `/session plan` で、CLI が作業をどのように管理しているか確認します。

## 🎊 ワークショップ完了

ここまでで **Mona Mayhem: GitHub Battle** の主要な演習を終えました。

### 作ったもの

- 設計に基づく Web アプリケーション
- レトロアーケード風でレスポンシブなランディングページ
- 実際の GitHub データを取得・比較する対戦画面
- 活動量を色で示す対話型グラフ
- エラー処理、読み込み表示、アクセシビリティの改善
- 複数の端末に対応するレイアウト

> **日本語版の補足：** 原文の振り返りには「複数ページのアプリ」とありますが、必須演習はメインページと API ルートが中心です。自分が実際に実装・確認した範囲を完了として記録してください。

### 練習したこと

| スキル | 内容 |
| --- | --- |
| コンテキストの設計 | 適切なファイル、指示、制約を渡す |
