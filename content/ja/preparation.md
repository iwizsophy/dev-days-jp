# Appの事前準備とUI確認

この教材では、GitHub Copilot Appを使った開発の進め方を学びます。画面の操作に加えて、その操作を行う目的と、結果を判断する根拠を説明できることを目指してください。画像と実際の配置が違うときは、現在の作業対象と目的を確認し、講師と操作経路を照合します。

<a id="prepare"></a>

## 事前準備の要件

Git、Node.js 24.19.0または `>=24.19.0 <25`、最新版のGitHub Copilot Appと、自分の演習用リポジトリを用意します。演習コピーは、教材用テンプレートの **Use this template** から作成してください。バージョン管理ツールを使う場合は、インストールした版に加えて、実際に動いているNode.jsの版を確認します。

[演習0](app/0-prerequisites.md)と[演習1](app/1-install-copilot-app.md)に沿って、課題8件、Appの起動、リポジトリ接続、Copilotの応答を確認します。教材リポジトリ `dev-days-jp` と、機能を実装する演習コピーの役割を区別してください。共通の初期状態を準備すると、生成されたコードの問題と環境の問題を切り分けやすくなります。

<a id="plans"></a>

## 対象プラン・組織権限・利用枠の確認

[GitHub公式のApp利用条件](https://docs.github.com/en/copilot/concepts/agents/github-copilot-app#availability)では、AppはすべてのCopilotプランを対象としています。受講前に、実際に使うアカウントでAppへ接続できること、利用枠、組織のAppポリシーを確認してください。

プランで利用できることと、演習を最後まで進める利用枠があることは別です。[プランの公式案内](https://docs.github.com/en/copilot/get-started/plans)を参照し、利用するプランの枠を確認してください。

<a id="switch"></a>

## 画面やメニュー配置が異なる場合

画面やメニューが教材の画像と異なる場合は、本文の操作対象、開始状態、項目名を照合してください。Issueは **Issues**、PRは **Pull requests** から開きます。目的の項目が見つからない場合は、現在の画面と、進めたい操作を講師に伝えてください。

<a id="mapping"></a>

## 学習の完了条件と成果の区別

コードが動くことに加えて、Appの機能を使って何を判断したかを確認します。Agent Mergeでは許可した操作とマージ結果、Canvasでは共有した情報と次の作業への使い方、Automationでは実行結果と要約の正確さを説明できることを目指してください。

受講者は、成果物を見せるだけでなく「何を期待し、どの結果を見て、その判断をしたか」を説明します。たとえばフィルターでは、選んだ条件と該当件数、0件の状態、解除後の一覧を比べることで、要件と動作を結び付けられます。

<a id="finish"></a>

## 演習終了後の確認と記録

コミット履歴、差分、テスト結果を確認し、最初の指示で伝わったことと、追加の説明が必要だったことを振り返ります。まだ確認できていないことや、次に試したいことも残してください。開発サーバーや不要な定期実行を停止し、成果物を保存します。
