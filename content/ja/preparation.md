# Appの事前準備とUI確認

この教材では、受講者がGitHub Copilot Appのエージェントと一緒に演習用サイトTailspin Toysの機能を変更し、実装からレビュー、マージまでの開発の進め方を学びます。画面を操作する目的と、コード差分・テスト・動作確認から結果を判断した根拠を説明できることを目指してください。教材の画像と自分の画面の配置が違うときは、本文が示す作業対象と目的を確認し、講師と操作経路を照合します。

<a id="prepare"></a>

## 事前準備の要件

Git、Node.js 24.19.0または `>=24.19.0 <25`、最新版のGitHub Copilot Appと、自分の演習用リポジトリを用意します。演習コピーは、Tailspin Toysの教材用テンプレートの **Use this template** から作成してください。Node.jsのバージョン管理ツールを使う場合は、インストールしたNode.jsの版に加えて、ターミナルやAppのセッションが実際に使う版を確認します。

[第1章](app/1-prerequisites.md)と[第2章](app/2-install-copilot-app.md)に沿って、自分の演習用リポジトリの課題8件、Appの起動とリポジトリ接続、Copilotの応答を確認します。教材を読むリポジトリ `dev-days-jp` と、Tailspin Toysの機能を実装する自分の演習用リポジトリの役割を区別してください。受講者が同じ初期状態から演習を始めると、エージェントが生成したコードの問題と、開発環境の問題を切り分けやすくなります。

<a id="plans"></a>

## 対象プラン・組織権限・利用枠の確認

[GitHub公式のApp利用条件](https://docs.github.com/en/copilot/concepts/agents/github-copilot-app#availability)では、AppはすべてのCopilotプランを対象としています。受講前に、実際に使うアカウントでAppへ接続できること、利用枠、組織のAppポリシーを確認してください。

プランで利用できることと、演習を最後まで進める利用枠があることは別です。[プランの公式案内](https://docs.github.com/en/copilot/get-started/plans)を参照し、利用するプランの枠を確認してください。

<a id="switch"></a>

## 画面やメニュー配置が異なる場合

GitHub Copilot Appの画面やメニューが教材の画像と異なる場合は、本文が示す操作対象、作業を始める状態、項目名を自分の画面と照合してください。Appでは、演習用リポジトリのIssueを **Issues**、PRを **Pull requests** から開きます。目的の項目が見つからない場合は、現在の画面と、進めたい操作を講師に伝えてください。

<a id="mapping"></a>

## 学習の完了条件と成果の区別

コードが動くことに加えて、Appの機能を使って何を判断したかを確認します。Agent Mergeでは許可した操作とマージ結果、Canvasでは共有した情報と次の作業への使い方、Automationでは実行結果と要約の正確さを説明できることを目指してください。

受講者は、変更したTailspin Toysの画面やコードを見せるだけでなく「何を期待し、どの結果を見て、その判断をしたか」を説明します。たとえばゲーム一覧の絞り込みでは、選んだカテゴリー・パブリッシャーの条件と該当件数、該当するゲームが0件の状態、条件を解除した後の一覧を比べることで、要件と実際の動作を結び付けられます。

<a id="finish"></a>

## 演習終了後の確認と記録

自分の演習用リポジトリのコミット履歴、コード差分、テスト結果を確認し、エージェントへ最初の指示で伝わったことと、追加の説明が必要だったことを振り返ります。実装した機能について、まだ確認できていないことや、次に試したいことも残してください。Tailspin Toysの開発サーバーや、演習で作成して不要になった定期実行を停止し、成果物を保存します。
