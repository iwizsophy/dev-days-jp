# Dev Days 日本語版

🌐 [English](README.md) | 日本語

このリポジトリは [github/dev-days](https://github.com/github/dev-days) の履歴を引き継いだ、非公開の日本語化作業用コピーです。GitHub 公式の日本語版ではありません。原本のライセンスと著作権表示は [LICENSE](LICENSE) に保持しています。

> 🚨 **公式の Dev Days イベントを開催し、プログラムの支援を受けるには、[イベント申請フォーム](https://gh.io/dev-days-2026)に記入して Dev Days チームの承認を得る必要があります。**
>
> このリポジトリには、Dev Days の主催者向けの技術コンテンツ、告知資料、運営手順が含まれています。

**Dev Days** は、**2026 年 9 月 1 日から 10 月 31 日**まで世界各地で開催される、対面形式のユーザーグループ企画です。開発者、技術に関心のある方、地域の技術コミュニティが集まり、実践的なハンズオンを通じて GitHub Copilot の可能性を探ります。

すべての開発者が参加でき、地域の技術コミュニティが運営します。各回は約 **2～3 時間**で、GitHub Copilot による AI 支援開発をテーマに、実際の開発の進め方、ハンズオン、ワークショップを扱います。

## 🏙️ 地域のイベントを探す・開催する

近くのイベントは [Luma カレンダー](https://gh.io/dev-days/calendar)で確認できます。

Dev Days の開催を希望するコミュニティリーダー向けに、このリポジトリには企画・運営・告知に必要な資料が揃っています。[イベント申請フォーム](https://gh.io/dev-days-2026)からお申し込みください。

> フォームへの記入だけでは開催が承認されたことにはなりません。イベントの計画を進める前に、チームからの確認をお待ちください。

### 🗓️ 開催形式

コミュニティに合わせて柔軟に構成できます。参加者の経験や対象者、利用できる設備に応じて、次の 2 つの形式を推奨します。

1. **セッションのみ：** GitHub Copilot の技術解説やデモを中心に進めます。
2. **セッション＋ワークショップ：** 技術セッションとハンズオンを組み合わせ、より深く実践的に学びます。

どちらも参加者同士のやり取りや実践を重視し、手を動かしながら学べる構成です。

## 日本語版の利用と更新

README、参加者向けトップページ、過去のワークショップ一覧を日本語化しています。外部リポジトリの教材、PowerPoint、主催者資料は翻訳対象に含めていません。

サイトは公開せず、ローカルで閲覧します。リポジトリのルートで次を実行し、[日本語ページ](http://localhost:8000/ja/)を開いてください。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory website
```

原本の更新は `upstream` から取り込めます。初回のみリモートを登録してください（登録済みなら不要です）。

```sh
git remote add upstream https://github.com/github/dev-days.git
git fetch upstream
git merge upstream/main
```

英語を原本とし、翻訳ファイルの `l10n-sync` コメントで参照コミットを記録します。コマンド、ファイル名、製品名は翻訳せず、更新後はリンクと日本語の表示を確認してください。公開用ワークフローはこのコピーでは実行しない設定にしています。
