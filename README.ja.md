### 🗓️ 開催形式

コミュニティに合わせて柔軟に構成できます。参加者の経験や対象者、利用できる設備に応じて、次の 2 つの形式を推奨します。

1. **セッションのみ：** GitHub Copilot の技術解説やデモを中心に進めます。
2. **セッション＋ワークショップ：** 技術セッションとハンズオンを組み合わせ、より深く実践的に学びます。

どちらも参加者同士のやり取りや実践を重視し、手を動かしながら学べる構成です。

## 日本語版の構成と演習の進め方

本教材の本編は **App シナリオ** です。演習は次の順序で一本の流れとして進めます。
1. 星評価の実装
2. カスタム指示の適用
3. フィルター機能の実装
4. Playwright MCP によるテスト
5. マージ（Agent Merge）
6. キャンバス（Canvas）による計画
7. 振り返り（Automation）

### 操作上の留意点と代替手段の扱い
- **現行 UI の確認**：受講者環境で画面の操作が見つからない場合は、推測で進めず、講師と現行 App の操作経路を確認し、講師デモやペア操作で補います。
- **CLI の位置づけ**：CLI 手順は作業を保全して先へ進めるための「緊急対応」であり、App 演習の完了には数えません。
- **機能体験の区別**：App 固有の機能（Agent Merge、Canvas、Automation）を通常の操作や代替手順で代用した場合、その機能を体験した扱いにはしません。

### 参考コースと講師向け資料
CLI独立コースとMona Mayhemは参考資料として収録していますが、本編の必須経路には含めません。Appは最新版を使用します。開催準備には[講師ガイド](website/ja/workshops/material/instructor.html)を参照してください。検証日・使用環境・確認範囲・結果は[検証記録](content/ja/material/verification.md)、原稿の更新手順は[教材の管理ガイド](content/ja/README.md)にまとめています。

## 開発・閲覧とリポジトリ運用方針

### ローカルでのサイト閲覧
教材サイトは外部へ公開せず、ローカル環境で閲覧します。リポジトリのルートで次を実行し、[日本語ページ](http://localhost:8000/ja/) を開いてください。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory website
```

### 参照元の「閲覧専用」原則
参照元リポジトリはすべて閲覧専用です。参照元への push、Pull Request、Issue 作成、コメント送信は一切行いません。また、上流の履歴を merge せず、[sources.json](content/ja/sources.json) の固定コミットとの差分を比較して、必要な修正のみを日本語原稿へ反映します。教材側の課題はこのリポジトリ内だけで管理します。

### 作業ブランチの取り扱い
ローカルの作業ブランチは `origin/main` に追跡させません。自身の GitHub リポジトリ等に公開する際は、同名の作業ブランチを明示して送信します。なお、静的サイトの公開用ワークフローはこのリポジトリでは実行しない設定になっています。
