この教材セットの進め方

App の操作と開発体験を学ぶ本編として、演習0〜8を順に進めます。完成したコードだけでなく、App のセッション、レビュー、MCP、Agent Merge、Canvas、Automation の操作を確認します。

操作できない場合は、講師による現行 App の案内、ペア操作、App のデモの順で対応します。CLI は講師向けの緊急対応で、本編を完了する代替経路ではありません。演習先は自分の Tailspin Toys コピーです。参照元への push・PR・Issue 作成は禁止です。

GitHub Copilot app は Copilot CLI を基盤とするデスクトップアプリケーションで、エージェント主導の開発を単一の作業用ワークスペースで実現します。並列エージェントセッション、切り替え可能なセッションモード、共有キャンバス、GitHub Issue と pull request のネイティブ管理機能を備えています。さらに、リベース、レビューのフィードバック、CI の修正、マージまで pull request を導く Agent Merge も利用できます。

一連のレッスンでは、アプリをインストールしてプロジェクトを設定した後、アプリのワークスペースと、テンプレートによって用意されたバックログを確認します。まず、星評価を追加する小さな変更に取り組みます。次に、Issue に基づいてカスタム指示の標準を追加し、分離されたエージェントセッションでフィルター機能を構築して、再利用可能なスキルで検証します。Playwright MCP server を追加して実際のブラウザーで機能を確認した後、段階的にマージの自動化を進め、最後は Agent Merge で pull request をマージします。最後に、共有キャンバスで共同作業し、繰り返し発生する作業を自動化します。アイデアから機能のマージまで、開発の一連の流れを体験できます。

前提条件

このワークショップに参加する前に、次のものを用意してください。

  • 有効な Copilot プランが設定された GitHub アカウント（Free を含む。全演習の完走に十分な利用枠があるか事前確認）
  • macOS、Linux、Windows のいずれかを実行するコンピューター
  • コンピューターにインストールされた Git

ヒント 有料プランを利用していない場合、認証済みの学生は GitHub Education を通じて GitHub Copilot を無料で利用できます。Copilot Student プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の各機能が含まれているため、対応する機能を利用できます。演習の完走に必要な利用枠は別途確認してください。

補足 Copilot app は codespace ではなく自分のコンピューターで実行するため、レッスン 0 では、アプリをインストールする前に Node.js をインストールし、プロジェクトの自分用コピーを作成します。

補足 Copilot Business または Copilot Enterprise を使用している場合、アプリを使用するには管理者が GitHub Copilot app ポリシー（CLI のポリシーとは別）を有効にする必要があります。
