この章の進め方： まず GitHub Web 上で演習用のコピーリポジトリを準備し、次章で Copilot App に接続します。2026年9月13日の実機確認により、現在の取得先は修正済みの非公開テンプレート（iwizsophy/dev-days-tailspin-template）に変更されています。テンプレート複製 API に加え、GitHub Web フォームを Private で送信し、コピー先に課題8件が自動作成されることを確認済みです（詳細は UI 確認表 を参照）。

GitHub Copilot app は、Copilot のエージェント機能と GitHub のリポジトリ管理を一元的に扱うデスクトップアプリケーションです。Issue や Pull Request に素早くアクセスでき、自律的なエージェントを活用した開発が可能です。 本ワークショップでは、Astro で構築された EC アプリ「Tailspin Toys」と GitHub Copilot app を組み合わせ、ローカル環境で開発を進めます。アプリをインストールする前に、前提環境として必要な Node.js をローカルに導入し、演習用リポジトリを用意します。

本レッスンでの到達目標は次の2点です。 - プロジェクトのビルドおよびテストをローカルで実行できるよう、適切なバージョンの Node.js をインストールする。 - 修正済みテンプレートから Tailspin Toys プロジェクトの演習用コピーを作成し、初期バックログを準備する。

1. Node.js のインストールとバージョン確認

本ワークショップの演習では、エージェントが実装した機能を検証するために、ローカル環境で Tailspin Toys のテストスイート（Vitest 単体テストおよび Playwright E2E テスト）を実行します。そのためには Node.js の環境が必須となります。

バージョン要件に関する重要な注意

プロジェクトの package.json に記載された最低要件だけでなく、固定された依存関係の要求を満たすバージョンを使用する必要があります。上流本体の最低条件記述だけでは一部の依存要求を満たさなかったため、本教材の実機検証では Node.js 24.19.0 を使用しています（配布テンプレートの .nvmrc は 24.19.0、engines.node は >=24.19.0 <25 に設定済みです）。

確認とインストール手順

プラットフォームを問わず、公式サイトのインストーラーを利用するのが最も確実です。

  1. ターミナル（Windows Terminal、macOS Terminal、または普段利用しているシェル）を開きます。

  2. 次のコマンドを実行し、現在インストールされている Node.js のバージョンを確認します。

    node --version

  3. 出力されたバージョンが演習コピーの要求（Node.js 24.19.0 推奨、>=24.19.0 <25）を満たしている場合は、次のセクションへ進んでください（講師は、Copilot App の実行環境でも同一の Node.js バージョンが参照されることを確認してください）。

ヒント Node.js が未導入であるか、またはバージョンが適合しない場合にのみ、以下のステップ 4〜9 を実行してください。

  1. Node.js のダウンロードページ を開きます。
  2. 使用している OS に合わせた LTS ビルドをダウンロードします。
  3. インストーラーを起動し、既定の設定でインストールを進めます（Windows の場合は、Add to PATH が有効になっていることを確認してください）。
  4. インストール完了後、新しいターミナルウィンドウを開き直します。

  5. 次のコマンドを実行し、新しく導入されたバージョンを確認します。

    node --version

  6. 要求バージョンが正しく表示されることを確認します（※Copilot App がすでに起動していた場合は一度完全に再起動し、古い環境変数が引き継がれないようにしてください）。

ヒント コンテナー環境を利用する場合、Docker Desktop が導入されていれば、ローカルに直接 Node.js をインストールする代わりにリポジトリ同梱の dev container を利用することも可能です。dev container 内には必要な Node.js 環境が最初から含まれています。

2. 演習用リポジトリの作成

受講者は、Tailspin Toys プロジェクトの演習用コピーを各自の GitHub アカウントに作成して作業を進めます。教材用の修正済み Tailspin Toys テンプレート を開き、テンプレートからのコピー作成手順 に沿って準備を行います。

テンプレートの仕様と修正内容

  • 取得先リポジトリ：iwizsophy/dev-days-tailspin-template
  • 教材対応版：v2026.09.13.1
  • アクセス権：非公開リポジトリのため、受講者は事前に講師から閲覧権限を受け取ってください。
  • 適用済み修正：上流の固定コミット bae0036 をベースに、PR Readiness の YAML エスケープ修正、MCP 設定（mcpServers）の修正、Node.js 24.19.0 の整合、依存パッケージの更新、およびエージェント環境向けのサーバー起動スクリプト（scripts/serve.mjs）の導入がすべて適用済みです。受講者が手動でパッチを当てる必要はありません（なお、星評価やフィルター機能などの演習の解答コードは含まれていません）。
  • リポジトリの峻別：教材自体のリポジトリ（dev-days-jp）と、コードを変更する演習用コピー（Tailspin Toys）を混同しないように注意してください。

重要 講師向けの配布判定基準： 配布版 v2026.09.13.1 は機能検査をすべてパスしており、依存性監査（npm audit）において Critical および High は 0 件です。ただし、drizzle-kit 配下に Moderate 4 件が残存しているため、受講者への本番配布前に配布元の WORKSHOP.md に記載された残件と確認範囲を必ず確認してください。
