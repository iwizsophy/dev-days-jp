GitHub Copilot app は、Copilot と GitHub の両方を一元的に扱うデスクトップアプリです。Issue や pull request にすばやくアクセスでき、もちろん GitHub Copilot を使った開発も可能です。このワークショップでは、Astro で構築された Tailspin Toys アプリと GitHub Copilot app を使い、ローカル環境で作業します。始める前に、Node.js がローカルにインストールされていることを確認してから、Copilot app をインストールします。

このレッスンでは、次の内容を学習します。

  • プロジェクトのテストを実行できるよう Node.js をインストールする。
  • テンプレートから Tailspin Toys プロジェクトの自分用コピーを作成する。

Node.js をインストールする

いくつかのレッスンでは、エージェントに機能を構築させ、Tailspin Toys のテストスイートをローカルで実行します。そのためには Node.js が必要です。コピーしたリポジトリの package.json に加え、固定された依存関係の要求も満たすバージョンを使用してください。2026年9月13日の検証では Node.js 24.19.0 を使用しました。

どのプラットフォームでも、公式インストーラーを使うのが最も簡単です。

  1. Windows Terminal、macOS のターミナル、または普段使用しているターミナルを開きます。

  2. 次のコマンドを実行し、Node.js のバージョンを確認します。配布テンプレートの .nvmrc は 24.19.0、engines.node は >=24.19.0 <25 です。上流本体の最低条件だけでは一部依存の要求を満たさなかったため、教材側で検証したバージョンを指定しています。

    node --version

  3. 演習コピーの依存関係の要求を満たすことを確認できた場合は、次のセクションに進めます。講師は App の実行環境でも同じバージョンが選択されることを確認してください。

ヒント Node.js がインストールされていない場合、または更新が必要な場合にのみ、以降の手順を実行してください。

  1. Node.js のダウンロードページを開きます。
  2. 使用しているオペレーティングシステム向けの LTS ビルドをダウンロードします。
  3. インストーラーを実行し、既定の設定を選択します。Windows では、Add to PATH を選択したままにします。
  4. インストールが完了したら、新しいターミナルを開きます。

  5. 新しいターミナルで次のコマンドを実行し、インストールを確認します。

    node --version

  6. インストールしたバージョンが表示され、手順2の条件を満たすことを確認します。App がすでに起動していた場合は再起動し、古い環境変数を使い続けないようにします。

ヒント コンテナーを使用する場合、Docker があれば、Node.js をローカルにインストールする代わりにリポジトリの dev container を使用できます。dev container には Node.js が含まれているため、両方を用意する必要はありません。

ラボ用リポジトリを設定する

Tailspin Toys プロジェクトの自分用コピーを使って作業します。教材用の修正済み Tailspin Toys テンプレートから、テンプレートからのコピー作成手順に沿って準備します。次のレッスンで、このリポジトリをアプリに接続します。

取得先は iwizsophy/dev-days-tailspin-template、教材対応版は v2026.09.13.1 です。非公開のため、参加者は事前に講師からアクセス権を受け取ってください。上流の固定コミット bae003609c8cff0c51d92658b8d3bd89450464f1 をコピーし、PR Readiness の YAML・MCP の設定修正、Node バージョン指定、依存更新、エージェント環境向けの起動修正を適用済みです。参加者による事前パッチの適用は不要です。星評価・フィルターなどの解答は含めていません。

Use this template は配布元の現在の main をコピーします。講師は開催前に workshop-source.json の配布版と sources.json に記録したコミットの対応を確認してください。タグを指定してコピーするボタンではありません。教材リポジトリ dev-days-jp と、コードを変更する Tailspin Toys のコピーは別です。

講師向けの配布判定： この版は機能検査を通過し、依存監査は Critical・High ともに0件です。drizzle-kit 配下に Moderate 4件が残るため、参加者への本番配布前に配布元の WORKSHOP.md の残件と確認範囲を確認してください。

  1. 新しいブラウザーウィンドウで、このラボの GitHub リポジトリ https://github.com/iwizsophy/dev-days-tailspin-template を開きます。

  2. ラボ用リポジトリのページで Use this template ボタンを選択し、Create a new repository を選択して、リポジトリの自分用コピーを作成します。
