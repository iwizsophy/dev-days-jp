計画と実装の反復を使って、ページ全体のテーマを変更します。最初に目指す見た目を考え、表示を調整しながら、CSS の実装を Copilot に任せます。

タスク1：レトロなテーマを計画する

VS Code では Copilot Chat を Plan モードにします。CLI では /plan を使うか、Shift+Tab で計画モードに切り替えます。次を入力してください。

このページを本格的なレトロアーケード風に変更したいです。次を含む見た目の全面改修を計画してください。
背景の CRT 走査線、ネオンサインのように明滅するタイトル、グラデーションが変化する VS バッジ、
ユーザー結果カードの光沢オーバーレイ、入力欄が浮かび上がるアニメーション、
緑と紫に変化する読み込み中の文字、グラフの四角形をホバーしたときの発光を含めてください。
暗い背景 #0a0a1a と、緑 #5fed83・紫 #8a2be2 のアクセントを維持してください。
Google Fonts の Press Start 2P を使うダークテーマにしてください。

提案された計画をすぐに採用せず、効果の内容を確認します。

  • 「ネオンの明滅を約3秒のゆっくりした周期にしてください」のように時間を調整する。
  • 「カードの光沢オーバーレイはどう動きますか？」と具体的な効果を質問する。
  • 違和感がある部分は方法を変更してもらう。

タスク2：テーマを実装する

計画に納得したら依頼します。

今確認したレトロアーケードのテーマ計画を実装してください。

スタイルシートには、次のような変更が入る可能性があります。

  • 走査線、ネオンの明滅、光沢、浮き上がり用の @keyframes
  • オーバーレイ用の ::before / ::after
  • テーマ色を管理する CSS カスタムプロパティ
  • 操作要素のトランジションとホバー状態

CLI では /diff でスタイルの変更を確認してから採用します。

タスク3：見た目を微調整する

表示が更新されない場合は、開発サーバーを Ctrl+C で停止して npm run dev で再起動し、ブラウザーを Ctrl+Shift+R で再読み込みします。

プレビューを開いたまま、次のような指示を試します。

  • 「走査線が強すぎるので、不透明度を 0.03 にしてください」
  • 「タイトルに、電気がちらつくような控えめな効果を追加してください」
  • 「VS バッジのパルスをもっとはっきりさせてください」

実際の見た目を確かめながら、アーケード筐体に合う雰囲気になるまで調整します。

タスク4：指示ファイルを更新する

大きなデザイン上の決定を指示ファイルに残し、次のリクエストでも方針を共有できるようにします。

VS Code のプロンプト：

copilot-instructions.md にデザインガイドの節を追加し、レトロアーケードの配色、フォント、アニメーションの方針を記載してください。

CLI のプロンプト：

リポジトリの指示に、レトロアーケードの短いデザインガイドを追加してください。
配色、フォント、アニメーションの方針と、新しい UI でもネオンの見た目を維持するルールを含めてください。

見た目を確認できたら、指示ファイルとデザインの変更を commit します。

✅ 第4章の完了

  • 実装前にデザインの方針を計画した。
  • 短い追加指示で見た目を調整した。
  • 大きな決定を指示に残し、デザインを一貫させた。
