App の事前準備と UI 確認

本編は App の操作を学ぶ演習です。画像と異なる場合も、まず講師と現行 App の操作を確認します。

事前準備

Git、Node.js 22.13以上、Copilot App、自分の Tailspin Toys コピーを準備します。演習0と演習1で起動・接続・応答を確認します。教材の dev-days-jp でアプリ実装の演習を実行しないでください。

プラン・権限・利用枠

2026年9月8日に参照した公式情報では App は全 Copilot プランが対象です。開催前に実アカウントで利用可否、残り利用枠、組織の App ポリシーを確認します。予備の CLI は別のポリシー確認が必要です。無料枠だけで全演習が完了する保証はありません。

UI が異なるとき

メニューが右クリックに移った可能性など、画像の位置だけでは判断できません。操作対象・目的・メニューの確認手順を講師と確認してください。現行経路が分からない場合は、App の講師デモまたはペア操作へ切り替えます。経過時間だけを理由に CLI へ移行しません。

学習の完了条件

機能実装の成功と、App での操作体験を区別します。通常 PR・Markdown・単発の要約を Agent Merge・Canvas・Automation の体験として記録しません。章別の検証状況を参照してください。

操作後の確認

対象リポジトリ・変更・テスト結果を確認し、App の操作を実施したか、デモを見たか、未実施かを記録します。終了時は開発サーバーや演習環境を停止し、作業を保存します。

講師向け資料

運営と操作支援 · 現行 UI と画像の確認表

CLI は実装の保全が必要な場合の緊急対応に限定します。章別の緊急対応と作業保全・復帰手順を参照してください。CLI が成功しても App 本編の完了には数えません。
