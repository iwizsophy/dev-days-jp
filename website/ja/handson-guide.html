App の事前準備と UI 確認

本教材の本編は、GitHub Copilot App を用いた開発ワークフローと操作体験を習得することを主目的としています。掲載スクリーンショットと実際の画面配置が異なっている場合でも、安易に自己流で進めず、まずは講師とともに現行 App の画面と操作手順を確認してください。

事前準備の要件

Git、Node.js 22.13 以上、GitHub Copilot App、およびご自身のアカウントへフォークした専用の Tailspin Toys リポジトリを事前にセットアップしてください。演習0 および 演習1 に沿って、アプリの起動、リポジトリ接続、および Copilot からの正常な応答を確認しておきます。なお、教材自体のリポジトリ（dev-days-jp）上で Tailspin Toys の実装作業を行わないようご注意ください。

対象プラン・組織権限・利用枠の確認

2026 年 9 月 8 日に参照した公式ドキュメント情報によると、GitHub Copilot App はすべての Copilot プランを対象として提供されています。ハンズオンの開催前に、使用する実アカウントでのアクセス権、利用可能なリクエスト枠、および所属組織における Copilot App の有効化ポリシーを必ず確認してください。なお、予備手段として用意している Copilot CLI を利用する場合も、組織側のポリシーで別途許可されている必要があります。また、Copilot の無料枠（Free プラン）のみで全 8 章の演習を最後まで完了できる保証はありません。

画面 UI やメニュー配置が異なる場合

参照元スクリーンショットに表示されていたボタンがコンテキストメニュー（右クリック）へ移設されているケースなど、画面上の固定位置だけでは操作の有無を正しく判断できない場合があります。画面差異に直面した際は、操作対象・目的・メニューの確認手順 に基づき、講師とともに現行バージョンの操作経路を確認してください。現行の確実な操作手順が判明しない場合は、受講者が単独で立ち往生するのを避け、講師による実演デモの見学やペア操作へ切り替えます。単に時間が経過したことだけを理由にして、安易に CLI への切り替えを行わないでください。

学習の完了条件と成果の区別

コードの実装機能が動作したという事実と、Copilot App 固有の UI 機能を体験できたという事実は明確に区別して評価します。通常の GitHub プルリクエスト作成、ローカル Markdown ファイルの手動作成、あるいは単発のチャット要約で作業を代替した場合、それらを Agent Merge、Canvas、および Automation の正規の体験実績として記録してはいけません。詳細な判定基準については、章別の検証状況 を参照してください。

演習終了後の確認と記録

対象リポジトリのコミット履歴、コードの変更内容、および自動テストの結果を確認したうえで、各章の作業について「App 上で実際に操作した」「講師デモを視聴した」「未実施」のいずれであったかを正確に記録してください。演習終了時には、バックグラウンドで起動している開発サーバーやコンテナ環境を適切に停止し、成果物を安全に保存してください。

講師・運営向けサポート資料

運営ガイドと操作支援 · 現行 UI と画面例の確認表

Copilot CLI の利用は、App が操作不能となり、受講者のコード実装進度を保全する必要が生じた場合の「緊急避難措置」に厳格に限定します。具体的な切り替え基準については、章別の緊急対応手順 および 作業保全・復帰手順 を確認してください。CLI によるコマンド実行が成功したとしても、それは App 本編の演習を完了した実績としてはカウントしません。
