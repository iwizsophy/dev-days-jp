Copilot App で開発の流れを体験する

架空の EC サイト「Tailspin Toys」を題材に、星評価コンポーネントやフィルター機能を追加しながら、カスタム指示、自動テスト、コードレビューを通じた最新の開発ワークフローを体験します。App 版の演習 0 から 8 までを単一の一貫したストーリーに沿って進めます。

全体の目次と到達目標を見る

掲載しているスクリーンショットは参照元教材の画面例です。現行の Copilot App ではメニューの配置や呼び出し手順が一部異なっている可能性があります。画面上で該当操作が見当たらない場合は、講師とともに手順を確認してください。なお、現行 UI との完全な突合検証は未完了の段階です。

今回の流れ

準備・接続 → 星評価の実装 → カスタム指示の適用 → フィルター機能の追加 → MCP によるテスト検証 → Agent Merge → Canvas での可視化 → 全体の振り返り

参加前の準備

Git、Node.js 22.13 以上、GitHub Copilot App、およびご自身のアカウントへフォークした Tailspin Toys リポジトリを準備し、Copilot App 上で正常に応答が得られることを確認しておきます。

教材の実施範囲と前提条件

本編で扱う現行 Copilot App の操作手順は、実機による全工程の実走検証が未完了の状態にあります。記載されている CLI 手順は講師向けの緊急回避策であり、App 演習の代用として完了扱いにするルートではありません。また、過去に実走検証済みの「CLI 独立コース」の検証結果は、本編とは明確に区別して管理しています。Agent Merge、Canvas、および Automation などの App 固有機能については、通常の Git 操作や単発のコマンド実行で代替したとしても、それらの機能を実際に体験した実績としては扱いません。

参考資料・補足コース

独立した CLI コースおよび Mona Mayhem は補講用の発展コンテンツです。本編ハンズオンの受講にあたっては必須ではありません。
